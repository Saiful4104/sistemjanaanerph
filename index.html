Jadual Waktu Saya

Tambah waktu pengajaran. Data disimpan dalam Cloud Firestore mengikut akaun guru.

RPT Berstruktur

Admin memasukkan tajuk, SK dan SP yang disahkan. Admin mengurus RPT berstruktur yang dikongsi kepada semua guru.

Pengurusan Guru

Admin mendaftarkan profil guru menggunakan UID daripada Firebase Authentication. Akaun emel/kata laluan mesti diwujudkan dahulu di Firebase Console → Authentication → Users → Add user.

Keselamatan: Borang ini tidak mencipta akaun Authentication dan tidak menyimpan kata laluan. Jangan gunakan akaun Admin untuk log masuk sebagai guru.

Senarai Akaun

Nyahaktif menghalang akses aplikasi, tetapi tidak memadam akaun Authentication. Untuk memadam akaun Authentication, urus secara berasingan dalam Firebase Console.
